# 綠空漫泡，綠川漾沫 | 新中城，城中心

> 「讓煩惱化為泡影，在綠川重拾清醒。」

這是一個專為「渴望日常心靈療癒」的都市人所設計的行銷影展專題網站。我們以台中 1908 綠空廊道與台中綠川水岸步道為雙核心，打造出一個無社交壓力、深度放鬆的日常藍綠空間體驗。

## 📖 策展理念 (Concept)

隨著都市化加速與生活步調緊湊，當代休閒產業轉向重視身心療癒。台中舊城區的綠川與綠空廊道，位處交通核心並融合生態與歷史記憶，形塑出免付費、隨時可及的都市綠洲。

本企劃旨在透過影像敘事，引導大眾放慢腳步，重新喚醒對自然空間與舊城區歷史的共鳴，在日常生活中找回內心的平靜。

## 🏛️ 展區介紹 (Venues)

*   **1908 Green Axis 綠空漫泡**
    由縱貫鐵路舊山線地面鐵道經空間再造，轉型為結合步行與藝文的線性綠空間。漫步於百年的鐵道記憶之上，將繁雜的思緒化為漫天輕盈的泡沫，這是一段屬於你與台中的高空散步。
*   **Green River 綠川漾沫**
    自日治時期水文運輸起，歷經市府水環境改善工程，轉型為兼具親水、教育與生態的市中心廊帶。在這裡，零門檻的順路休憩，讓你在日常的縫隙中獲得最純粹的心靈療癒。

## 🎞️ 企劃放映室 (Screening)

本專題包含一支前導短片。講述主角在排山倒海的催促與窒息感中，行經綠空廊道時穿越象徵壓力分界的泡泡，展開了一場尋找風景的漫步之旅。最終在綠川河畔放下手機，伴隨泡泡破裂的聲響展現出內心的徹底釋懷。

## 🎨 視覺風格與技術架構

本網站採用**韓系文學風格**設計，強調留白、細緻的線條與字體層次，營造出如同閱讀實體雜誌般的沉浸感。

*   **色彩計畫 (Color Palette):**
    *   `#F9F8F6` (米白) - 溫潤的紙張底色
    *   `#739E82` (青綠) - 綠川水岸意象
    *   `#4A6B5D` (橄欖綠) - 綠空植被意象
    *   `#A75D4D` (磚紅) - 視覺亮點與互動回饋
*   **技術堆疊 (Tech Stack):**
    *   HTML5 (語意化標籤與 SEO 優化)
    *   CSS3 (CSS Grid 網格系統、Flexbox 彈性佈局)
    *   響應式設計 (RWD)，完美適應桌機、平板與手機瀏覽
    *   Google Fonts (`Noto Serif TC` 思源宋體)
