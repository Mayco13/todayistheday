# 數位行銷程式設計基礎 - 大二影展專題介紹

**專題名稱**：《綠空漫泡，綠川漾沫》
**作者**：行銷二甲 李舒涵 (Mayco)

## Vibe Coding Prompt (使用的 AI 指令)

以下是我在開發此專案時，提供給 AI (如 Cursor / Windsurf / ChatGPT) 的 Vibe Coding 指令：

> **Role**: 你是一位專業的網頁前端工程師。
> **Task**: 請幫我製作一個符合大二學生影展專題介紹的單頁式完整網頁 (Single Page Application)。
> 
> **【專題內容設定】**
> - 標題：《綠空漫泡，綠川漾沫》
> - Slogan：讓煩惱化為泡影，在綠川重拾清醒。
> - 核心概念：針對「日常心靈療癒型」客群，將台中舊城區的綠川水岸與綠空廊道，打造成無社交壓力、深度放鬆的日常自然藍綠空間。
> - 劇情大綱：主角在被工作與課業排山倒海催促的高壓日常中，因為一支短影音決定出門喘息。行經綠空廊道時穿過象徵壓力分界的透明泡泡，並在復古商店「酷庫」買了一張舊明信片，展開尋找風景的漫步。最終在綠川河畔坐下，伴隨泡泡破裂聲徹底釋懷微笑。
> 
> **【技術與架構要求】**
> 1. **檔案結構**：必須將 CSS 獨立切割放置於 `css/style.css` 檔案中，所有圖片放置於 `images` 資料夾內。
> 2. **版面配置 (Layout)**：參考側邊欄導覽設計。使用 CSS Grid System 進行排版，左側固定為 Sidebar 導覽列，右側為主要內容區塊 (Main Content)。
> 3. **響應式設計 (RWD)**：需能在手機裝置上完美顯示，手機版時導覽列需移至頂部或底部。
> 4. **SEO 優化**：包含完整的 `<title>`、`<meta name="description">`、`<meta name="author">` 以及語意化標籤 (`<header>`, `<nav>`, `<section>`, `<article>`)。
> 5. **色彩計畫**：以綠色為主色調（Meadow Green #0C6038、Outerspace #2D4C39），並以黃 (Mustard Green #808847)、紅 (Crimson #8B0000)、古銅色 (Peach #F1D2A1) 作為點綴。
> 
> **【區塊規劃】**
> - `#home` (首頁)：滿版大圖與 Slogan。
> - `#about` (企劃理念)：說明都市綠洲與心靈療癒的價值主張。
> - `#story` (劇情大綱)：說明焦躁的日常到綠川重拾清醒的過程。
> - `#gallery` (幕後側拍)：使用 Grid 排列劇照與側拍紀錄圖片。
